Octocam Firmware Update

Install the latest firmware over USB, right from this page. Nothing to install on your computer.

How it works

  1. Open this page in Google Chrome or Microsoft Edge on a Windows PC or Mac (Safari can't install firmware).
  2. Connect your Octocam device with a USB-C data cable (some charging-only cables don't work).
  3. Click Install for your device below and pick its port in the list (on Windows usually USB JTAG/serial debug unit, on a Mac cu.usbmodem…), then click Connect.
  4. Click Install again. Leave "Erase device" unticked to keep your settings, password, network name and pairings.
  5. Wait until it says the installation is complete (about a minute), then unplug the device.

Device not in the list / connection fails?
  • Try a different USB cable or USB port. Many short cables only charge and can't carry data.
  • Put the board into download mode: hold its BOOT button, plug in the USB cable (or press and release RESET), then let go of BOOT. Click Install again.
  • Close other programs that might use the port (for example the Arduino IDE serial monitor).
  • After an install in download mode, press RESET or unplug and replug the device so it starts the new firmware.
Updating without a computer

Every Octocam device can also be updated over WiFi from its own web app: connect your phone to the device's WiFi, open http://8.8.8.8 in your browser and use Firmware Update with the .bin file you got from Octocam.
